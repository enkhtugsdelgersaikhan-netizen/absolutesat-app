About the data: SAT values prefer the latest usable Common Data Set; when a school does not currently report testing, LexLogica uses the latest available IPEDS testing fields or derives missing values from the reported section/composite range. Every displayed SAT score is normalized to a 10-point increment—no values ending in 5. A derived median is the rounded midpoint of the lower and upper quartiles when no true median is published. Test-optional and test-free policies can make historical or submitter-only ranges unrepresentative of the full entering class.
